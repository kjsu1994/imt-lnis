I/Q 생성

관측값과 일관된 선행 GPS 항법정보가 준비된 위성으로 생성합니다. 항법정보가 없는 위성은 제외하며, 생성 가능한 위성이 4개 미만이면 실행하지 않습니다.

처리내용
프레임 구성AFS 전송과 같은 SB 구성기로 위성별 프레임을 생성합니다. 12초 길이의 프레임 내용을 신호 파일에서 반복합니다.
신호 합성위성별 PRN 신호를 생성하고 합산합니다. 합성 잡음을 추가하며 원본 RAWX의 위성별 C/N0를 정량적으로 재현하는 설정은 아닙니다.
양자화·저장I·Q 각각을 −3, −1, +1, +3으로 양자화하고 signed int8 한 바이트씩 교차 저장합니다. 2비트 양자화와 파일 저장 단위는 다릅니다.
검증 정보생성 시 파일 해시를 구합니다. 전송 시작 시에는 파일 존재·크기를 확인하고 생성 당시 해시를 재사용합니다.
기본 파일 크기 = 90초 × 12,000,000 samples/s × 2 bytes = 2,160,000,000 bytes

90초는 신호 파일의 길이입니다. 최종 공통 지연 PVT 비교는 선택한 1 Epoch를 대상으로 하며 RF 추적 관측값은 진단용으로 구분합니다.

시각 변환과 PVT 계산

A는 프레임 기준시각, S는 시험 시작 접수 시각, R은 수신 본문 완료 시각입니다. 이 시각은 원본 GNSS 관측 시각 t₀와 구분합니다.

프레임 저장: Tᵢ = A − Pᵢ/c 시험 시작 기준 보정: T*ᵢ = Tᵢ + (S − A) = S − Pᵢ/c 수신 의사거리: P′ᵢ = c(R − T*ᵢ) = Pᵢ + cΔt 계산용 관측 시각: t′₀ = t₀ + Δt · Δt = R − S

t₀ − Pᵢ/c는 의사거리에서 추정한 위성 송신 시각입니다. 원본 의사거리에는 시계·대기 등의 오차가 포함되므로 정확한 물리 송신 시각으로 취급하지 않습니다.

관측 시각과 의사거리를 함께 이동하면 t′₀ − P′ᵢ/c = t₀ − Pᵢ/c가 됩니다. 코드에서 위성 좌표를 별도로 고정하지 않으며, RTKLIB가 송신 시각 추정과 위성 시계 보정을 거쳐 위치를 계산합니다.

수집 후 시작 전 대기는 제외합니다. PC 간 시계 차이와 수치 연산·보정 모델의 영향은 결과 해석 시 고려합니다. 펨토초 저장 단위는 실제 시각 정확도를 뜻하지 않습니다.

항목확인 방법

판정 해석MEASURED는 측정 완료이며 허용오차 기반 합격 판정이 아닙니다. PARTIAL은 부분 비교, INCONCLUSIVE는 비교 불가 상태입니다. 데이터 일치 여부와 구분합니다.
자료 조회 지연수신 계산 결과를 보관하고 비교자료 조회를 재시도합니다. 기록은 보관 정책과 관리자 삭제 대상입니다.
Clock Bias 잔차 = (수신 Bias − Reference Bias) − Δt

측정 지연, Clock Bias 증가량·잔차, 위치·속도 차이를 함께 확인합니다. 위치 차이만으로 데이터 전달 성공을 판단하지 않습니다. PC 간 시계 차이는 지연 측정에 포함될 수 있습니다.

라우터와 LNIS의 역할

화면의 DTN은 ION, HDTN은 HDTN 라우터를 선택합니다. 번들 저장·라우팅·전달은 외부 어댑터와 라우터가 처리합니다. LNIS는 testId별 접수·데이터 일치 여부·PVT 결과를 기록합니다.

여러 시험의 도착 순서가 달라도 testId로 구분합니다. 특정 경로의 라우팅 동작을 확인하려면 라우터 로그와 접촉 계획·설정을 함께 확인해야 합니다.

수신 원문 기록

수신 원문 기록: 인증을 통과한 요청은 JSON·시험 검증 전에 원문을 기록합니다. 16 MiB 초과 본문은 앞 16 MiB만 보관하고 거절합니다. 기록은 보관 정책과 관리자 삭제 대상입니다.

원문 상태 발생 조건 본문 보존 여부 후속 처리 및 시스템 동작

AFTER_CANCEL 사용자가 대기 종료한 후 지연 도착 원문 보관 정책 적용 계산 미수행, 사후 분석 및 감사용 원문 데이터만 유지
REJECTED 인증 후 JSON·시험·전달 형식 검증 실패 실패 본문 보관 정책 적용 오류 응답과 원문 상태·사유 확인. 인증 실패는 원문 기록 대상에서 제외
